## 🚀 Descripción del Proyecto
Sitio web portafolio desarrollado para presentar proyectos web, diseñado con un tema oscuro moderno, interactividad con JavaScript y estilos optimizados.

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura semántica.
- **Tailwind CSS:** Diseño y estilos responsivos.
- **JavaScript (JS):** Dinamismo e interacciones.
- **Git & GitHub Pages:** Control de versiones y despliegue en vivo.

---

## 🤖 Declaración de Uso de Inteligencia Artificial (IA)
En cumplimiento con los requerimientos académicos, se declara el uso de Inteligencia Artificial (IA) como herramienta de asistencia durante el desarrollo de este proyecto:

- **Herramienta utilizada:** Gemini (Google DeepMind).
- **Usos específicos:**
  - Asistencia en la resolución de problemas de sincronización de Git, gestión de ramas (`main`, `rama-capturas`) y comandos de terminal.
  - Apoyo en la estructuración de la documentación técnica y generación del archivo `README.md`.
  - Guía en la configuración del despliegue en GitHub Pages.

---

## 📁 Estructura del Repositorio
- `/css`: Archivos de hojas de estilo.
- `/js`: Lógica y scripts interactivos.
- `/capturas`: Evidencia de comandos Git ejecutados en terminal.
